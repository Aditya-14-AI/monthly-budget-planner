# Monthly Expense Tracker Dashboard

A modern monthly expense tracker built with Next.js, TailwindCSS, shadcn-style components, Recharts, and Zustand localStorage persistence.

## Features

- Dashboard cards: total spending, budget remaining, transaction count
- Add expense modal with amount, category, description, date, payment method
- Expense categories: food, transport, rent, entertainment, utilities, shopping, other
- Analytics charts: pie, line, and bar charts via Recharts
- Transaction table with sorting and delete actions
- Responsive layout with sidebar navigation
- Dark mode toggle

## Run locally

```bash
npm install
npm run dev
```
